## Worker boundaries

Each launch must name one task above and exact Markdown `## Allowed edit surfaces`, with one narrow relative path/glob per line. Draft writers change only their component's versioned contract/plan/specimen surfaces, not runtime code, shared registries, package metadata, ODD tracking or GitHub.

No nested agents, commits, staging, branch creation, push, PR, merge, installations, server launch or deletion by workers. Parent owns those operations and browser captures. Heavy gates are serialized through `/tmp/egdev-gates.lock`, packed through `/tmp/egdev-packed.lock`, with explicit memory/time limits. New/unapproved tokens or dependencies stop the affected scope, not the entire pool.

Runtime work cannot be made eligible by a writer's own verdict. Complete preparation outputs are returned for owner review, while the same worker session may take the next eligible preparation task instead of waiting idly. Record later approvals and fresh assignments before T9–T15.
