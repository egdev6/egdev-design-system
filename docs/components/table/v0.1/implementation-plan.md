## 3. Public API and naming

A generic `Table<TRow extends TableRow>` consumes `TableRow = { id: string }`, ordered `TableColumn<TRow>[]` and `TRow[]`; accessors see the consumer's row type. Columns require unique stable `id`, nonempty `header`, pure `cell(row)`; optional `format` (`text` default, `number`, `code`, `actions`), `rowHeader`, `hideHeader` (false) and pure `sortValue` (finite number or string). First eligible row-header declaration wins, otherwise first column; actions ignore `rowHeader` and `sortValue`. Duplicate IDs and non-finite keys are unsupported caller data. Details ignores `hideHeader` and `sortValue`.

| Own prop | Contract / default |
| --- | --- |
| `label`, `hideLabel` | Required nonempty caption; hidden accessibly when `hideLabel` is true (default false). |
| `columns`, `rows` | Required; at least one column; rows may be empty. |
| `variant`, `size`, `maxHeight` | `data` or `details` (default data); `sm` or `md` density (default md); optional `sm`/`md`/`lg` viewport cap, absent by default. |
| `activeRowId` | Optional consumer-designated current row, independent of selection; unknown ID marks none. |
| `sort`, `defaultSort`, `onSortChange` | Data only; controlled `TableSort \| null`, initial uncontrolled sort defaults null, callback receives next `{columnId, direction}`. |
| `selectable`, `value`, `defaultValue`, `onValueChange` | Data only; multiple selection defaults off; controlled `string[]`, uncontrolled initial `[]`, callback receives next IDs. |
| `messages` | Partial overrides: `selectAll: "Select all rows"`, `selectRow: "Select"`, `empty: "No rows"`. |
| `className` | Frame outer layout only; margin, width constraints and grid/flex placement, not paint, geometry, overflow or internals. |

Details excludes sort and selection props using `never`. Export named `Table`, `TableProps`, `TableColumn`, `TableRow`, `TableSort`, `TableSortDirection`, `TableColumnFormat`, `TableVariant`, `TableSize`, `TableMaxHeight`, `TableMessages`. No ref, `asChild`, children, subcomponents or style appearance permission. Use the issue's exact `TableNativeProps` Omit boundary: `children`, `className`, `role`, `aria-label`, `aria-labelledby`, `dangerouslySetInnerHTML`, `defaultValue`, `onChange`; forward allowed native attributes to the table, not the frame, while protecting computed semantics and attributes. Owner decision, 2026-11-01 (`odd/tasks/organisms-build.md` L13): “Mantener style, no soportado (Recomendado)”. Retain native `style` in the public type and forward it without stripping; using it for appearance is unsupported.

[Registry workflow](../../../../skills/_shared/component-contract.md#prop-naming-registry): the issue maps `label` → `accessible-name`, `hideLabel` → `visually-hidden-label`, `variant` → `visual-treatment`, `size` → `preset-dimensions`, `value` → `primary-value`, `defaultValue` → `initial-uncontrolled-value`, `onValueChange` → `interactive-value-change`, `messages` → `localized-messages`. Its eight new-at-drafting candidates are `columns` → `table-columns`, `rows` → `table-rows`, `sort` → `table-sort`, `defaultSort` → `initial-uncontrolled-sort`, `onSortChange` → `sort-change`, `selectable` → `row-selection`, `activeRowId` → `active-row`, `maxHeight` → `viewport-max-height`. The issue records these entries as approved under an assistant-applied delegated naming receipt, not independent per-payload owner review; do not call them newly unregistered or create duplicates. Recheck current registry names, meanings, aliases, status and exceptions before adding Table usages; component-specific column fields are not separate conventions. No usage hash exists until source is reviewed.

## 4. Engine, composition and accessibility

- Radix has no table/sort primitive applicable here: use native `table`, `caption`, `thead`, `tbody`, `tr`, `th scope="col"`, `th scope="row"`, `td`; never `grid`, cell arrow navigation, `aria-selected` or row-click activation. Compose `ScrollAreaPrimitive.Root`, `Viewport`, horizontal Scrollbar, optional vertical Scrollbar when capped, Thumb and Corner. No Portal or `asChild`. Frame is `eg-table-wrap`, table is `eg-table`; retain `eg-table__num`, `eg-table__acts`, `eg-table__code` where specified.
- A caption names the table and its ID names the viewport group, always one `tabIndex=0` stop. VisuallyHidden wraps hidden caption/header and selection text. Generate instance-safe IDs with `useId`; row-header IDs derive from base ID and display position, not arbitrary row IDs. A row Checkbox is labelled by hidden `messages.selectRow` plus its row-header cell; select-all uses `messages.selectAll`. Checkbox owns Space interaction, mixed state and disabled rendering; Table supplies a 44px coarse-pointer label target. Consumer controls own their row-inclusive accessible names.
- Header buttons are native `button type="button"` with visible or visually hidden header text and decorative Icon `arrow-down`, not IconButton (icon-only) or Button (different visible-label Material recipe); Text is display/eyebrow-only and does not match this table typography. Button/IconButton remain optional consumer cell content. Native Enter/Space activate sort; expose only the sorted header's `aria-sort`, no live region or invented sort announcement. Icon appears only sorted, rotated for ascending. Keep focus on the activated header while sorting; viewport uses native arrow/Page scrolling, Tab traverses viewport then controls and leaves normally. No table-owned key handler or focus trap.
- Independent controlled states use supplied `sort` (including null) and `value`; otherwise initial defaults apply once. Never switch modes mid-mount. Header activation starts ascending, toggles direction; another column starts ascending. Invalid, non-sortable or actions sort is unsorted. Stable comparator: numeric for two numbers, otherwise `Intl.Collator(undefined, { numeric: true, sensitivity: 'base' })` on strings; invert comparisons, never reverse ties. Rows update under current sort. Runtime locale may differ between SSR and client; document pre-sorted rows or numeric keys as mitigation.
- Row toggle appends/removes its ID. Select-all adds missing current IDs in display order or removes all current IDs when fully selected; preserve off-row IDs. It is mixed for partial current selection and disabled unchecked for empty rows. Sorting never changes selection or active ID. Active `aria-current="true"` takes visual precedence over selected `data-state="selected"`, then hover. Empty body spans all columns including selection, sort remains usable. Details has no header row, sort or selection.

## 5. Material and token recipe

Use static CVA in `types.ts` and per-part `cn()` in the hook. Compose the existing Surface `surfaceVariants` on the ScrollArea Root with `tone: surface-1`, `elevation: 1`, `padding: none`, `radius: lg`, and `overflow-hidden`; this uses the Surface sheen, hairline, edge and elevation tokens, not a copied Surface engine. Scrollbar tracks use the Surface well recipe; thumbs use `bg-border-control rounded-full`. Preserve the frame's focus visibility with an inset token outline on the viewport. No handwritten shadows, gradients, colors or new tokens.

- Header band: `bg-surface-2 border-b border-border-default font-display text-label-eyebrow uppercase text-fg-muted whitespace-nowrap text-start`. Caption: `text-label-default text-fg-muted text-start px-4 py-3`; hidden caption has no visible box.
- Body cells: `text-label-default`, body-weight and meta-line-height token references, `text-fg-secondary align-top border-b border-border-subtle`; last row removes border. Data row headers use `text-fg-default`, normal case, no background, static position; details row headers are muted, nowrap and shrink to `w-[1%]`.
- Density md: body `py-3 px-4`, header `py-2.5 px-4`; sm: both `py-2 px-3`. Code is `font-mono text-code text-fg-brand-raised`; number is end-aligned, tabular and nowrap; actions end-aligned, nowrap, `w-[1%]`. Empty is `py-6 px-4 text-center text-fg-muted`.
- Hover `bg-fg-default/3`, selected `bg-surface-3`, active `bg-bg-brand-subtle` plus first-cell logical start bar using `--focus-width` and `bg-action-primary-solid-bg`; explicitly enforce active > selected > hover. Caps are static `max-h-[calc(var(--space-24)*3)]`, `*4`, `*6`, with sticky column headers only. Sort uses inherited typography, `inline-flex items-center gap-1`, hover/sorted foreground and `size-3` glyph; coarse-pointer sort minimum height 44px. Focus uses existing focus tokens; no authored motion or translucent overlay.
- Neutralize conflicting legacy rules on preserved markers, including sticky body row headers, first-cell color and frame overflow, then verify the emitted cascade. `className` merges last only for supported outer layout; `twMerge` is not universal override precedence. Validate all utilities and token availability against current build before coding; unresolved recipe/token gaps require owner confirmation, not invented values or token edits.

## 6. Test-first sequence and integration

1. **RED:** Add public-interface behavior tests for AC-01–AC-18 in focused increments before their implementations: native table/caption/header association, defaults and hidden labels; sort click/Enter/Space, stable ties, numerical/string/mixed cases, controlled/null/invalid state and rerender; independent selection, mixed/all/empty/off-row IDs and emitted order; active precedence, details restrictions, empty messages, native forwarding and protected semantics. Assert callbacks and unchanged state on rejected/controlled interactions. Add negative generic type fixtures and accessibility queries; no `data-testid` or whole-class snapshots.
2. **GREEN:** Implement minimum types, hook and JSX against each failing case, using existing Checkbox and Radix rather than recreating their behavior. Add preserve checks for touched shared integrations; test public root/part markers, supported merge precedence and legacy CSS neutralization. Run focused tests first. No implementation claims arise from this document.
3. **Browser and package:** Verify horizontal and capped vertical scroll, sticky headers, focus retention and visible unclipped focus, 44px coarse-pointer targets, 200% zoom/reflow, row-state computed precedence, both visual scenarios and differences against their recorded conditions. Manually verify AT header association, `aria-sort` and checkbox naming/state; browser or DOM tests alone do not certify AT. Test compiled CSS/static CVA scan and packed consumers without a Tailwind compiler, including React 18 and 19 and root exports/generic types.
4. **Controls and integrations:** Validate real docgen extraction, registered enhancer/inference and zero owned metadata diagnostics, then browser widgets. Use explicit `@control` on every own prop and union branch: text for `label`/`activeRowId`, selects for finite enums, booleans for `hideLabel`/`selectable`, false with concrete reasons and story references for complex values/callbacks. Only actual constants get `@default`; absence and derived fallbacks are descriptions. No per-component `argTypes`, adapters or fake defaults. Run parent-authorized focused and full local Verify set, package consumption, `pnpm props:check` and `pnpm test:props`; owner approval and RDD review remain separate.
