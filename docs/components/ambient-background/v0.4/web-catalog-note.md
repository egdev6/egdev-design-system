# AmbientBackground v0.4 — web catalog note (appended, not an amendment)

**Appended 2026-11-02 on top of the approved v0.4 text. It rewrites nothing and reopens no decision.** The [contract recovery](contract-recovery.md) and its `## 1. Purpose and scope` payload, including the recorded `contentSHA256`, stay exactly as approved.

## What this note records

- The v0.4 exclusion of the director choreography **stays valid for this component**: AmbientBackground still owns no scroll choreography, no zones, no blend bands, no 3D/background exclusion rule and no time-based interpolation between profiles. Its list of non-goals is unchanged.
- Choreography is now **owned by the future HomeTemplate in `@egdev/effects`**, not by the web app. This is the web catalog v0.1 owner approval recorded on 2026-11-02 in [owner-approvals.md](../../web-catalog/v0.1/owner-approvals.md) (source draft: [cataloging-draft.md](../../web-catalog/v0.1/cataloging-draft.md)). The [web consumer amendment](../../../CATALOGACION.md#web-consumer-amendment-approved-2026-11-02) states it as a rule: the component still does not choreograph, and the template contract owns it instead.
- Everything else in v0.4 is unaffected: atom-effect classification in `@egdev/effects`, profile and opacity inputs, the reduced-motion fallback, the root marker, the published taxonomy delta and the pending browser/packed-consumer verification.
- No variant gap was approved for this component by the web catalog.

This note is a catalog decision only. The HomeTemplate contract still needs its own approved spec, then a separately approved plan, before any code.
