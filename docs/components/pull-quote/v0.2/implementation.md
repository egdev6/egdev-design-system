## Decisions applied

| Decisions | Implementation |
| --- | --- |
| D1 | Native `figure > blockquote > p` plus optional `figcaption`. Display never creates a heading, level or role. |
| D2, D7 | No Text/Heading composition. Quote-specific CVA recipes use the new `text-quote-pull` / `text-quote-display` tokens; `cn.ts` registers both sizes for typography merging. |
| D3, D5 | Plain-string `text`, `accent`, `source`; `variant` pull/display (default pull). Text and accent are React text in one paragraph; no quotation marks, separators or prefixes. Display casing is the `uppercase` utility only. |
| D4 | `cite` is destructured and forwarded only to the blockquote; blank cite is omitted. Never rendered, linked or fetched. |
| D6 | Blank text renders nothing (no figure, caption or accent) and warns once per transition in development through an effect (`process.env.NODE_ENV !== 'production'`, or no `process`). Blank accent/source/cite are omitted. HTML-looking strings render literally. |
| D8–D9 | Pull: `max-w-quote-pull`, logical `border-s-[length:calc(var(--border-width)*2)]` brand filet, `py-0.5 ps-4.5`, `gap-3`, after `border-0 p-0` resets so RTL keeps no physical left filet. Display: `gap-5.5 max-w-none border-0 p-0`. |
| D10 | `tone` canvas/raised (default canvas) changes only the accent between `text-fg-brand-default` and `text-fg-brand-raised`. No background, shadow, sheen or motion. |
| D11 | Caption: `font-sans text-body-default text-fg-secondary m-0` (16px/1.6/500). |
| D12 | Markers `eg-quote`, `eg-quote__text`, `eg-quote__accent`, `eg-quote__source`; no `eg-quote--display`. Six files, **No stylesheet**, no internal modules, ref, `asChild`, state or events. |

Legacy `.eg-quote*` rules stay in `@layer components`; the new utilities win from the utilities layer. Root `className` is merged last with `cn()` for outer margins, narrower widths and placement; owned measure/typography/filet/tone are not supported overrides. Untyped `children`, `role` and `dangerouslySetInnerHTML` are discarded before forwarding. Public exports are exactly `PullQuote`, `PullQuoteProps`, `PullQuoteVariant`, `PullQuoteTone`; the hook and CVA recipes stay internal.
