3. **Pure scene math first:** Port the reference seed, seven preclipped extrusion polygons and original piece draw order. 4. **Private factory/ownership:** Pass initialized exact three namespace, owned canvas, parsed root token colors and normalized scene inputs/size into a typed instance-local factory. No top-level browser APIs/value THREE import. Module returns a private render/resize/dispose handle; hook alone schedules frames, so engine creates no second rAF chain. Register each geometry/material/instanced backing resource/halo texture/renderer immediately after acquisition for partial-boot cleanup; shared cap/side materials are deduplicated. Engine exposes no React/application state.
5. **Lazy eligible boot:** Hook subscribes to size/visibility/preferences and stores latest normalized inputs in refs. Mounted-root width/height>0, document/native hidden false and opacity>0 permit one initialization attempt/generation. Import literal bare `three` only here, optionally load private engine module here too. Suspended SSR/initial mounts allocate no GPU scene and trigger no import. Missing WebGL/required color parse, import rejection, failed partial factory or render→terminal fallback, never package installer/CDN/retry. Guard both async resolution and first-frame callbacks by active generation/root identity; late results cannot boot a detached root.
6. **First-frame/state coordinator:** Deterministic SSR/hydration loading fallback; after successful eligible frame select canvas atomically and update React state only on real state transitions. Keep fallback in DOM with hook-derived hidden presentation; no crossfade/is-gl-on classes. Failure > stopped > loading > static > running exactly. Failed mount remains fallback on props/visibility/context-restored; stop before first frame retains SVG, after success retains last canvas. Zero width/height is suspension, not failure. Current opacity/native hidden still affect paint even in fallback.
7. **One scheduler:** Hook owns a single cancellable rAF/draw handle. Store props without per-frame React updates; calculate dt clamp/smoothing with no hidden-time catch-up. Scene-family changes snap at next eligible frame, intro once per mount/active time only. Reduced-motion entry cancels loop/pointer, completes intro and draws fixed approved pose only when eligible; prop/size changes coalesce to at most one static draw. Resume resets timing, does not replay intro. Opacity stopping threshold is **exactly zero**, never source <=.003 (that threshold belongs only to eased Lab debris).
8. **Resize/tier/pointer:** Observe root bounds with ResizeObserver even while initialization is deferred, plus visibility/native hidden updates and live reduced/coarse/DPR changes; DPR media subscriptions rearm after changes and clean up individually. Resize renderer backing store with style-update false and camera-local assembled fit90%; no slot/projection-page offsets, mask, scroll listener or viewport canvas. Low/root width≤760 or coarse gives44/cap1.25; otherwise100/cap1.75. Root-bound passive window mouse listener attaches only initialized eligible normal hero/outro + literal true; reset target AND active tilt on outside/blur/window exit/disable/scene/stop/failure/reduced. Never capture/intercept pointer or wake loop from touch/pen.
9. **Terminal error/cleanup:** Context loss prevents default then invalidates/stops/selects fallback; no restoration retry. On error/unmount/Strict cleanup, first invalidate generation and cancel draw chain, then attempt every observer/media/DPR/visibility/window/context subscription removal and every GPU disposal in isolation. Use actual r160-supported resource APIs checked against installed typings; track instance buffers as well as geometries, shared materials, halo texture and renderer. A failing disposer cannot abort remaining attempts or revive async work; clear ownership/attempt once, cleanup idempotent. Browser/driver/consumer callback exceptions are not a universal no-throw guarantee.
10. **GREEN/triangulate/package:** Focused tests pass, including failures at each acquisition and disposal boundary, refs/Strict/two instances and forbidden native/layout overrides.
