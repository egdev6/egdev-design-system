## 2. Future API and surfaces

The organism is a passive `div.eg-blog-grid`; host composes SectionHeader above and supplies its named section/SectionShell register. BlogGrid paints no surface, shadow, glass or halo. It supplies no content, routing, date formatting, handler, state, landmark, Radix behavior or new dependency. Feature is a consumer ArticleFeature whole-card link; its action label is paint, and its visible badge participates in the default accessible name. The row anchor is exactly `<li><ListItem variant="editorial" asChild><a>…</a></ListItem></li>`; no `ListItemActions`, nested link or button. Archive is an optional independent named Link or equivalent anchor, after the list, never inside a row. Consumer owns correct names, heading ranks, alternatives, destinations and stable row keys.

Root has required `children: ReactNode`, native `ComponentPropsWithoutRef<'div'>` excluding conflicting children and `dangerouslySetInnerHTML`, and layout-only `className`; compatible native `data-*`/`aria-*` pass through. `BlogGridFeature.children: ReactElement`, `BlogGridRows.children: ReactNode`, `BlogGridRow.children: ReactElement`, and `BlogGridArchive.children: ReactElement` are required; parts accept children only. One Feature and Rows, zero or more Rows' Row children, at most one Archive. Empty Rows produces no `ul`, while a supplied archive remains. No descendant cloning or runtime semantic inspection, implicit content, part className, root `asChild`, ref or automatic link validation is promised. ReactElement types cannot enforce those consumer obligations. `cn()` merges supported root placement classes last for recognized conflicts only; it does not promise arbitrary paint overrides or universal cascade precedence.

Subject to gates and later explicit authorization, writer owns six meaningful files in `packages/ui/src/organisms/blog-grid/`: `types.ts` (public types, static CVA, English JSDoc/Controls), `useBlogGrid.ts` (meaningful slot/empty handling and per-part `cn()`), `BlogGrid.tsx` (JSX only), `BlogGrid.test.tsx`, `BlogGrid.stories.tsx`, `index.ts` (named components and types). No extra module. **No stylesheet**, conditional on emission and cascade proof; failure requires a separately approved meaningful role, not a dummy stylesheet or legacy change. Empty detection must handle ordinary empty arrays and null/false children without inspecting descendant element types; test the public contract and do not claim detection of opaque components that render nothing.

Parent owns shared exports, production/story scanning, metadata and package fixtures, registry decisions and catalog integration. `packages/ui/src/styles/compiled.css` currently lists organism sources individually, so future integration must add BlogGrid `types.ts`; inspect `.storybook/preview.css` for any separate story-only source requirement. No child implementation, token, dependency, lockfile or frozen contract changes are implied.

## 3. Proposed layout and exact emission inventory

The compound API permits Feature, Rows and Archive as root siblings, so avoid inventing an implicit list-column wrapper or inspecting/cloning children. Candidate root is a two-column, two-row grid: wide columns `minmax(0,7fr) minmax(0,5fr)`, rows `minmax(0,1fr) auto`; Feature spans both grid rows in column 1, Rows occupies column 2 row 1, Archive column 2 row 2. The archive has `--space-2` top margin and start alignment. Set root column gap `--space-5` and row gap zero; Rows' `ul` is flex column with `--space-3` gap and full available height. Each `li` is a flex item with `flex: 1 1 0%` and content-driven minimum; its direct editorial anchor fills the `li`. Feature's direct anchor fills its wrapper. This allocates remaining column height to rows, not the archive; neither child card's Material recipe is replaced. Prove any direct-anchor sizing is compatible with ArticleFeature/ListItem's supported class surfaces; never inject props or override their paint.

At ≤1080px explicitly reset grid to one column, auto rows and automatic placements/spans, and reset Rows' `ul`, `li` and anchor heights/flex to natural content flow. Feature → Rows → Archive remains DOM and visual order. Without rows, the empty grid track must not introduce phantom height or gap; prove both with and without archive. Unequal content may impose different minimum heights: test equal heights when content fits, and ensure long content increases the layout without clipping rather than forcing equal heights by truncation. Test narrow embedded hosts even above the viewport threshold; no container breakpoint is substituted. If the track sizing cycle or direct-child anchor sizing cannot satisfy the approved contract in real layout, stop at gate 2.

**Exact arbitrary/variant candidate inventory for parent emission proof** (literal static CVA strings, not dynamic interpolation; all other listed utilities are static ordinary utilities):

- Root: `grid`, `grid-cols-[minmax(0,7fr)_minmax(0,5fr)]`, `grid-rows-[minmax(0,1fr)_auto]`, `gap-x-5`, `gap-y-0`, `items-stretch`, `min-w-0`, `[@media(width<=1080px)]:grid-cols-1`, `[@media(width<=1080px)]:grid-rows-none`.
- Feature wrapper: `min-w-0`, `col-start-1`, `row-start-1`, `row-span-2`, `[&>a]:h-full`, `[@media(width<=1080px)]:col-auto`, `[@media(width<=1080px)]:row-auto`, `[@media(width<=1080px)]:row-span-1`, `[@media(width<=1080px)]:[&>a]:h-auto`.
- Rows (`ul` when nonempty): `min-w-0`, `col-start-2`, `row-start-1`, `flex`, `flex-col`, `h-full`, `gap-3`, `list-none`, `m-0`, `p-0`, `[@media(width<=1080px)]:col-auto`, `[@media(width<=1080px)]:row-auto`, `[@media(width<=1080px)]:h-auto`.
- Each Row (`li`): `min-w-0`, `flex-1`, `[&>a]:h-full`, `[@media(width<=1080px)]:flex-none`, `[@media(width<=1080px)]:[&>a]:h-auto`.
- Archive wrapper: `min-w-0`, `col-start-2`, `row-start-2`, `self-start`, `mt-2`, `[@media(width<=1080px)]:col-auto`, `[@media(width<=1080px)]:row-auto`.

Prove every arbitrary and variant string above, including nested arbitrary variants, in the actual production build with correct declarations, media conditions and layer order; also verify ordinary `gap-*`, `mt-2`, flex, placement and sizing resolve against the installed tokens, including no-preflight consumer behavior. `grid-cols-[7fr_5fr]` is **not** the proposed utility: its tracks lack the approved `minmax(0,…)`; prove the exact minmax candidate instead. Parent's installed-compiler evidence in [batch 1 record](../../web-catalog/v0.1/layer-d-plan-approvals.md) and task L31: `md:` emits nothing; static `max-[X]:`/`min-[X]:` and arbitrary media variants emit; `max-[X]:` is exclusive `width < X`. The approved Footer plan uses `[@media(width<=860px)]:` for its inclusive boundary. This is precedent, not proof that any exact BlogGrid candidate above emits or has the intended cascade. If any candidate changes, enumerate and prove its replacement before approval/implementation; do not silently add a variant.
