- **Branch:** `feat/tabs-edge-fade`.

## Technical approach

What Tailwind cannot express lives in `tabs.css`; everything else stays static CVA in `types.ts`. No new `eg-*` class marker.

1. **Token** (`packages/tokens/src/theme.css`, next to `--mask-section-fade-*`): direction-agnostic, physical left/right stops.

   ```css
   --mask-scroll-fade-inline: linear-gradient(to right, transparent, #000 var(--mask-fade-left, 0px), #000 calc(100% - var(--mask-fade-right, 0px)), transparent);
   ```

   `tokens.css` is regenerated by `pnpm tokens` (build artifact, git-ignored).
2. **`packages/ui/src/molecules/tabs/tabs.css`** (approved role: scroll-driven edge masking), in `@layer components`: `@property --eg-tabs-fade-start` / `--eg-tabs-fade-end` (`<length>`, `0px`, non-inherited) and `@keyframes eg-tabs-edge-fade` (start fade only at the end edge, both edges between 10% and 90%, start edge only at 100%). Imported from `styles/index.css` like `gauge.css`.
3. **`types.ts`, list CVA:** applies to `underline` and to `segmented` / `outline` with `fullWidth`:
   - fade size `[--eg-tabs-fade-size:calc(var(--spacing)*8)]` and `scroll-px-8` (replaces `scroll-px-1.5`, which it contains);
   - physical mapping `[--mask-fade-left:var(--eg-tabs-fade-start)]` / `[--mask-fade-right:var(--eg-tabs-fade-end)]`, swapped with `rtl:`;
   - under `supports-[animation-timeline:scroll()]:` only: `mask-image` (plus `-webkit-`), and animation **longhands** (`animation-name`, `-timing-function`, `-fill-mode`, `-duration:auto`, `-timeline:scroll(self_inline)`). The `animation` shorthand would reset `animation-timeline` and utility order is not guaranteed.
   Without overflow the scroll timeline is inactive, the custom properties stay `0px` and the mask is fully opaque (AC-01), with no JavaScript.
4. **Unchanged:** `Tabs.tsx`, `useTabs.ts`, API, exports, `index.ts`.
